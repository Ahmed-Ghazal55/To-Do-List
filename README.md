# To-Do List (Legacy JavaScript Practice)

An early HTML, CSS and vanilla JavaScript learning exercise. **Preserved intentionally** as part of my development history; not presented as a production task-management system.

## Features in source
Add tasks, filter all/pending/completed, edit/delete tasks and store the list in the browser's `localStorage`.

## Run
Open `index.html` in a browser. No npm/build tools required.

## Maintenance plan (documentation-first)
1. Verify task creation, editing, deleting, completion and persistence after reload.
2. Use DOM-safe text rendering and validation for user-provided task names.
3. Improve keyboard accessibility, labels, mobile layout and empty states.
4. Add a small manual test checklist and screenshots.
5. Keep this repository as a legacy learning sample; develop complex task apps separately.
